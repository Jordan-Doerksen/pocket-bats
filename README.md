# Pocket Bats

A small site about bats. One page, made for a phone first. Short true facts and small cute games.
Static HTML/CSS/JS. No build step. No dependencies.

## View the site

Open `index.html` in a browser. Or serve the folder with a local server, for example
`python -m http.server`.

## File map

- `index.html` — the page. All facts are readable with JS off.
- `styles/` — the token file and the site styles. `js/` — the config, the games, and the wiring.
- `design/` — mockups. `docs/` — the decisions, the architecture, and this record set.

## Rules
